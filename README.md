# VenueRoot — العربية أولًا

موقع تعريفي تفاعلي بواجهة عربية من اليمين إلى اليسار، وقصة مرئية تتحرك مع التمرير.

## تشغيل محلي

يتطلب Node.js 18 أو أحدث. من هذا المجلد شغّل:

```sh
node serve.mjs
```

ثم افتح http://127.0.0.1:4173. يجب تشغيل خادم محلي لأن تسلسل الصور يقرأ ملف manifest عبر fetch؛ لا يكفي فتح HTML مباشرة.

## تعديل الموقع

- `dist/content.js`: نصوص فصول القصة والخطوات والقطاعات والأسئلة الشائعة. `signupUrl` فارغ عمدًا؛ ضع فيه رابط التسجيل الحقيقي عند توفره.
- `dist/index.html`: العنوان والوصف والنص الافتتاحي الثابت والجزء التعريفي الأول.
- `dist/styles.css`: ألوان وخطوط وتخطيط الواجهة الأساسية.
- `dist/details.css`: أقسام المنصة والمخطط والهاتف ولوحة الهوية.
- `dist/app.js`: الأقسام التفاعلية ونموذج ملخص المشروع.
- `dist/scroll.js`: التمرير، توزيع زمن المشاهد والذاكرة المؤقتة المحدودة.
- `dist/mobile.css` و`dist/navigation.js`: تجربة الهاتف والقائمة الثابتة وإدارة التركيز.
- `dist/assets/mobile/`: فيديو الهاتف كتسلسل صور رأسي مستقل، وصورة البداية وملف manifest.
- `dist/mobile-preview.html`: معاينة الهاتف بمقاسات متعددة لنفس الموقع داخل إطار متجاوب.
- `dist/style-tile.html`: لوحة الهوية باستخدام نفس ملفات التصميم.
- `dist/assets/manifest.json`: عدد صور الحركة وأبعادها ومساراتها.
- `brand/`: أصول PNG المولدة والفيديو الأصلي وبيانات الإنتاج.

التعديلات على هذه الملفات لا تنشر تلقائيًا. بعد التعديل، تحقق محليًا وأعد نشر النسخة عبر Sites باستخدام هوية المشروع الموجودة في `.openai/hosting.json`. لا تنشئ موقعًا جديدًا لتحديث هذا الموقع.

## السلوك التجريبي

مخطط المشروع يحفظ مسودة محليًا في متصفح الزائر، مع تنزيل ملخص نصي وحذف المسودة. لا تُرسل معلومات إلى VenueRoot أو موردين، ولا يتم إنشاء حساب أو عقد. بيانات النموذج لا تمثل عروض أسعار حقيقية. واجهة خطوات المنصة تصور توضيحي وليست لوحة تشغيل خلفية.

## الهوية والأصول

الشعار المقترح مولّد عبر Higgsfield ومحفوظ كـ PNG. `assets/logo.webp` قصّ لاستخدام الويب من الأصل نفسه. لا يُقدّم بوصفه شعار SVG متجهيًا. الصور والفيديو تم توليدها عبر Higgsfield MCP. الفيديو صامت ومستخدم كتسلسل صور للتمرير.

تفاصيل القياسات والاختبارات والافتراضات في `PRODUCTION.md`.

تُختار نسخة الهاتف عند عرض 700 بكسل أو أقل، قبل طلب صور الحركة. لا تُحمّل النسختان معًا. تُلغى طلبات النسخة السابقة وتُحرر الصور المفكوكة عند تغيير المقاس عبر هذا الحد. مع تقليل الحركة، لا تُطلب ملفات الحركة أو manifest، وتظهر صورة ثابتة وتخطيط طبيعي. رابط معاينة الهاتف المحلي: http://127.0.0.1:4173/mobile-preview.html.
